## Publish on GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `rk-catters`.
2. Extract this ZIP on your computer.
3. Upload the contents of this folder (make sure `index.html` is at the repository root).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish your site; the public URL will appear in the Pages settings.

## Editing
- Change text and menu items in `index.html`.
- Change colours and layout in `style.css`.
- Change WhatsApp pre-filled message or numbers in `script.js`.
- Add more photos/videos to `assets/` and add matching gallery entries in `index.html`.

Note: The uploaded video files are included in the project and may make the ZIP large. For smoother loading, you can later host large videos on YouTube or a video hosting service and embed them instead.
